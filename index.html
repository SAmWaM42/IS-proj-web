Inside the system

Behavioural architecture

A compact research implementation combining internal state, semantic memory and reinforcement learning in a simulated companion.

Affective state

Attachment, stress, energy and curiosity provide a compact representation of the agent's changing internal condition.

Semantic memory

Structured facts retain relevant interaction knowledge, allowing later behaviour to reflect what the agent has learned.

Tabular Q-learning

A discrete action policy learns from interaction outcomes within a bounded simulated environment.

Launch guide

Quickstart

Download the package, extract it, then launch the bundled application script.

bash · AnimalAgent
# Download the Linux package
curl -fL "${window.location.origin}/api/downloads/latest?platform=linux" -o AnimalAgent-Linux.zip

# Extract and enter the application directory
unzip AnimalAgent-Linux.zip -d AnimalAgent
cd AnimalAgent/AnimalAgent

# Launch the packaged desktop application
./run-animal-agent.sh

The archive includes the runtime launcher and packaged dependencies. Follow any release-specific notes included with the package.
